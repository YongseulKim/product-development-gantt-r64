# PC 업무관리 검수

공개용 합성 사례로 검수합니다. 날짜와 상품명은 테스트를 위한 값이며 실제 업무 기록으로 사용하지 않습니다.

## 범위

- 개정별 독립 저장·조회 및 동명 업무의 분리
- 부분 완료와 전체 완료, 서면 협의와 부서 회신 구분
- 반복 일정 지연·복수 선행자료·회의 예정/확정
- 완료 업무의 재산출·수정 차수
- 개발·검증·부분 오픈 단계 분리
- 한 개정 안의 안건별 일정, 공유 자료의 변경 범위
- 필수조건 제외와 업무 자체 제외의 차이
- 동시 편집 충돌, HTML 보관 및 새 상품 이관
- PC 드래그·양끝 기간 조절·다중 이동·확대·키보드 실행 취소

## 방법

Chromium을 기본으로 1280/1440/1920px 창에서 확인합니다. 검수 DB·프로필·다운로드는 임시 폴더로 분리합니다. fixture는 입력 준비용이며 원문 업무 데이터를 가져오지 않습니다. 사례 명세는 `tests/fixtures/channel_scenarios.json`에 있습니다.

결과는 통과·부분 통과·실패·입력 확인·기능 공백을 구분합니다. 전용 기능이 없는 항목을 통과로 표시하지 않습니다. 실제 Ctrl+클릭 선택 과정과 지원범위 밖 마우스 드래그 등은 별도 수동 검수가 필요합니다.

검수 증거는 로컬 `docs/evidence/`에 생성됩니다. 파일이나 화면에 입력한 실제 업무 자료가 공개 커밋에 섞이지 않도록 해당 디렉터리는 기본 제외합니다.

## 주의할 현행 동작

6영업일 회의 간격 강제와 후행 일정 자동 앞당김 미지원은 알려진 항목입니다. 해당 규칙과 상충하는 시나리오는 실패 또는 부분 통과로 보고하며, 기대값을 임의로 바꿔 전체 통과로 만들지 않습니다.

## 공개용 사본 기본 검수

2026-10-20, Termux의 Chromium 155 환경에서 서버 API 21개, 날짜 계산 18개, JavaScript 구문 4개 블록, 브라우저 핵심 흐름 19개가 통과했습니다. 다른 OS에서의 실행은 아직 확인하지 않았습니다. 업무 시나리오 전체가 통과했다는 의미는 아닙니다.

## 시스템 메모 삭제 (2026-10-21)

시스템이 남긴 업무 메모에도 삭제 버튼을 제공합니다. 삭제는 실행 취소/다시 실행으로 복구할 수 있습니다. 사용자 메모와 ID가 같아도 선택한 종류의 기록만 삭제하도록 구분했습니다. 브라우저 회귀 검사 23개(삭제·복구·저장·HTML 이관 포함), 날짜 계산 18개, JavaScript 구문 4개 블록이 통과했습니다.
