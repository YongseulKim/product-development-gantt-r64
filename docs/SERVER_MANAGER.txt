상품개발 간트차트 서버 관리자 · Windows x64

Python을 별도로 설치할 필요가 없습니다.
ZIP을 새 폴더에 풀고 GanttServerManager.exe를 실행하세요.
처음 실행하면 같은 폴더에 기본 HTML과 초기 데이터 파일을 준비하고 서버를 시작합니다.
서버 데이터는 data 폴더, 로그는 logs 폴더에 저장됩니다.

기존 서버를 이어서 사용하는 경우
1. 먼저 기존 START_SERVER.cmd 또는 server.py로 실행한 서버를 중지하세요.
2. index.html, initial_project.json, data 폴더가 있는 기존 서버 폴더에 EXE를 넣으세요.
3. EXE를 실행하면 기존 파일을 덮어쓰지 않고 그 폴더의 데이터로 서버를 시작합니다.
   다른 위치에 EXE를 두었다면 '중지' 후 '폴더 선택'으로 기존 서버 폴더를 선택하고 다시 시작하세요.
4. 운영 서버는 같은 데이터 폴더에 하나만 실행하세요.

기능
- 서버 시작, 중지, 재시작
- 한글 로그와 로그 파일 보관
- 이 PC 및 다른 PC에서 접속할 주소 표시
- 접속 중인 IP 목록: 열린 브라우저가 보내는 신호 기준, 최근 60초 이내 응답 IP
  같은 IP에서 여러 화면을 열어도 IP 한 개로 표시합니다.
  기존에 열어둔 브라우저는 새로고침해야 접속 현황에 나타납니다.
- 응답이 지연되면 상태 표시, 필요 시 재시작
- 백그라운드 실행: 관리 창을 숨기고 알림 영역에 아이콘 표시
- 알림 영역 메뉴: 관리 창 열기, 서버 재시작, 종료

창 닫기(X)는 실행 중일 때 백그라운드로 전환합니다.
서버까지 끝내려면 관리 창의 '종료' 또는 알림 영역의 '종료'를 사용하세요.
Windows 서비스나 부팅 시 자동 실행 방식은 아니므로, Windows에서 로그아웃하면 유지되지 않습니다.

다른 PC에서는 관리 창에 표시된 공유 주소로 접속합니다.
기존 서버와 같은 네트워크·방화벽 설정을 사용합니다.

HTML 업데이트는 서버 폴더의 index.html을 교체하면 됩니다.
EXE 옆에 이미 있는 HTML을 우선 사용하므로 기존 운영 HTML이 자동 교체되지는 않습니다.
실행 중 생성되는 data 폴더를 삭제하지 마세요. 기존 자동 백업도 유지됩니다.
